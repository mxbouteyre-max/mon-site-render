Index.html

La page index.html permet de lancer l'extraction de données de différents sites web d'enseigne d'optique en France (31).

Elle réfence 31 codes python contenant les scripts d'extraction. Ils sont nommés de la façon suivante : export + le site dont il fait l'extraction. Pour lancer l'extraction, il suffit de cocher les codes, et donc les sites, dont on souhaite récolter les données. Puis il faut lancer l'extraction en cliquant sur le bouton Lancer.

Le suivi de la progression de l'extraction des données peut être observé dans la console juste à droite du menu de sélection.

Une fois que l'ensemble des scripts sélectionnés a fini de s'exécuter, le fichier xlsx qui contient les données extraites peut être téléchargé en cliquant sur le bouton télécharger xlsx.

Merger_excel.html

L'interface merger_excel.html permet de fusionner et de mettre à jour un fichier excel.

Le principe est simple. On y dépose le fichier que l'on souhaite actualiser. Ce fichier s'appelle le fichier maître. On dépose également un second fichier qui lui est appelé fichier mis à jour (c'est le fichier contenant les données qui vont actualiser celles du fichier maître).

Une fois les fichiers déposés, il faut renseigner dans l'interface quelles colonnes des fichiers vont servir à faire le lien pour actualiser les données. L'interface renseigne le nombre d'associations qu'elle peut faire avec les variables sélectionnées, ce qui permet d'ajuster pour trouver celles faisant le plus de correspondances.

Ensuite on sélectionne les options que l'on veut pour le fichier final. Cette interface peut garder pour le fichier final (Le fichier maître mis a jour) le formatage du fichier maître. C'est-à-dire les couleurs ou les options de style appliquées à ce fichier. Ensuite on choisit le mode d'opération, la tâche que l'on souhaite réaliser à l'aide de l'interface. On peut soit fusionner des fichiers soit surligner les lignes communes aux deux. Une fois ce paramètrage effectué, il reste à sélectionner les colonnes que l'on souhaite conserver. L'interface renseigne si les colonnes sont ajoutées, mises-à-jour ou conserver.

Enfin l'interface permet de visualiser les premières lignes du fichier avant de télécharger le fichier au format xlsx.
