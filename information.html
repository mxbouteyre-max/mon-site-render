Guide d'utilisation des trois outils du site

⚙
Extraction de données optiques
index.html

Cette interface permet de lancer automatiquement des scripts Python qui collectent les données des boutiques de 30 enseignes d'optique françaises (Krys, Optic 2000, Optical Center, Grand Optical, etc.). Chaque script se connecte au site de l'enseigne et récupère les informations de chaque magasin : nom, adresse, code postal, ville, département, téléphone, email, coordonnées GPS et URL.

Comment utiliser
1
Sélectionner les scripts — Cliquer sur les scripts souhaités dans la liste de gauche pour les cocher. La sélection est limitée à 10 scripts maximum par exécution. Le nombre de scripts sélectionnés et le temps estimé s'affichent en bas du panneau.
2
Lancer l'extraction — Cliquer sur le bouton Lancer. Les scripts s'exécutent les uns après les autres. La progression est visible dans la barre en haut et dans la file d'exécution (tuiles).
3
Suivre l'avancement — La console à droite affiche en temps réel la sortie de chaque script. Chaque tuile passe de en attente → run → ✓ ok ou ✗ err. Le chrono estimé dans la sidebar décompte le temps restant et vire au rouge en cas de dépassement.
4
Télécharger les données — Une fois l'exécution terminée, le bouton Télécharger les données (.xlsx) apparaît dans la barre du bas. Le fichier généré contient toutes les données collectées. Les fichiers sont automatiquement supprimés du serveur après le téléchargement.
Fonctionnalités
⏱ Chrono estimé
Calcule et affiche le temps total estimé selon les scripts sélectionnés. Décompte en temps réel pendant l'exécution, vire en ambre sous les 20% restants et en rouge si le temps est dépassé.
📊 Mode d'export
Le toggle en bas à droite permet de choisir entre feuille unique (toutes les données dans un seul onglet) ou multi-feuilles (un onglet par enseigne).
⏹ Arrêt d'urgence
Le bouton Arrêter interrompt l'exécution proprement après la fin du script en cours. Les scripts non encore lancés sont annulés.
🗑 Suppression auto
Les fichiers CSV/XLSX générés par les scripts sont automatiquement supprimés du serveur après le téléchargement, pour ne pas saturer l'espace disque sur Render.
⚠
La limite de 10 scripts par exécution est recommandée pour éviter les timeouts sur Render (plan gratuit). Pour extraire plus de 10 enseignes, lancer plusieurs fois l'extraction par tranches.

Fusion et mise à jour Excel
excel-merger.html

Cet outil permet de comparer, fusionner ou mettre à jour deux fichiers Excel sans avoir à ouvrir Excel. Il fonctionne entièrement dans le navigateur : aucune donnée n'est envoyée à un serveur. Il accepte les formats .xlsx, .xls et .csv.

Comment utiliser
1
Déposer les fichiers — Glisser ou sélectionner le fichier maître (celui à mettre à jour) et le fichier de mise à jour (celui qui contient les nouvelles données). Les premières lignes de chaque fichier s'affichent en aperçu.
2
Choisir la clé de correspondance — Sélectionner la colonne commune aux deux fichiers qui sert d'identifiant unique (ex. : numéro de téléphone, SIRET, nom). L'interface indique combien de lignes correspondent avec la clé choisie, ce qui permet d'ajuster pour maximiser les correspondances.
3
Configurer les options — Choisir si l'on souhaite conserver le formatage du fichier maître (couleurs, styles), puis sélectionner le mode d'opération : Fusionner ou Surligner.
4
Choisir les colonnes — Sélectionner les colonnes à inclure dans le fichier final. L'interface indique si chaque colonne sera ajoutée (nouvelle), mise à jour (existante enrichie) ou conservée (inchangée).
5
Prévisualiser et télécharger — Un aperçu des premières lignes s'affiche avant l'export. Cliquer sur le bouton de téléchargement pour obtenir le fichier .xlsx final.
Modes d'opération
🔀 Mode Fusion
Enrichit le fichier maître avec les données du fichier de mise à jour. Les lignes communes sont mises à jour, les colonnes nouvelles sont ajoutées. Le résultat est un fichier maître à jour.
🎨 Mode Surlignage
Génère un fichier Excel identique au maître mais avec les lignes présentes dans les deux fichiers surlignées dans la couleur choisie. Utile pour identifier rapidement les doublons ou les correspondances.
ℹ
L'outil fonctionne entièrement côté navigateur (JavaScript). Aucune donnée n'est transmise à un serveur — les fichiers ne quittent pas l'ordinateur.

Alumni Scout — Parser LinkedIn
parser_linkedIn.html

Cet outil analyse des profils LinkedIn sauvegardés en HTML et en extrait automatiquement les informations clés : nom, localisation, expérience professionnelle la plus récente, formation, email et URL du profil. Il détecte également si la personne est diplômée de l'Institut Supérieur d'Optique (ISO).

Comment capturer un profil LinkedIn
1
Méthode rapide (recommandée) — Glisser le bouton 📌 Sauvegarder profil LinkedIn dans la barre de favoris du navigateur (une seule fois). Ensuite, sur n'importe quel profil LinkedIn, cliquer sur ce favori : le fichier HTML léger se télécharge instantanément, nommé d'après le nom de la personne.
2
Méthode manuelle — Sur un profil LinkedIn, faire Ctrl+S et choisir « Page Web, complète » (pas "HTML uniquement"). Seul le fichier .html est nécessaire, le dossier de ressources peut être ignoré.
Comment analyser les profils
1
Charger les fichiers — Glisser un ou plusieurs fichiers .html dans la zone de dépôt, ou cliquer pour les sélectionner. Plusieurs profils peuvent être chargés et analysés en une seule fois.
2
Analyser — Cliquer sur ⚡ Analyser les profils. L'extraction est instantanée. Chaque fichier passe en ✓ (succès) ou ✕ (erreur) dans la liste.
3
Consulter et exporter — Les données extraites s'affichent dans le tableau à droite. Cliquer sur ↓ Télécharger CSV pour exporter l'ensemble en fichier CSV, compatible Excel.

🎓
La détection ISO (Institut Supérieur d'Optique) analyse l'ensemble de la section Formation, pas seulement la plus récente. Elle détecte aussi les mentions par ID d'école LinkedIn (school/10454973).
⚠
L'outil fonctionne uniquement avec des profils LinkedIn sauvegardés en page complète (ou via le bookmarklet). Un fichier sauvegardé en "HTML uniquement" ne contient pas le contenu rendu par JavaScript et sera vide.
